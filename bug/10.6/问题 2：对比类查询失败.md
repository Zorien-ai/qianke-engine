# 问题 2：对比类查询失败

案例 OPT-05：高客单 vs 普通用户偏好差异

LLM 只召回了 3 个高客单用户，没召回任何"普通用户"，所以无法对比。

根因：一次检索只会返回一个候选池。对比类查询需要分别检索两组。

解决方向：Query Decomposition（查询分解）——把"高客单 vs 普通用户"拆成两个子查询，分别检索后再让 LLM 对比。

```python
# 伪代码
sub_queries = llm.decompose(query)
# → ["高客单用户偏好", "普通用户偏好"]

results_a = hybrid_search(sub_queries[0])
results_b = hybrid_search(sub_queries[1])
answer = llm.compare(query, results_a, results_b)
```
