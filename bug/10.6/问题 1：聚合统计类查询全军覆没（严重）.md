# 问题 1：聚合统计类查询全军覆没（严重）

| 案例 | 问法 | 失败表现 |
|---|---|---|
| DA-04 | 美妆用户客单价分布 | 只看了 3 个用户，说"样本量太小" |
| MGT-01 | 本周高价值用户规模 | 只看了 3 个用户，拒答 |
| OPT-06 | 母婴偏好用户在哪些城市集中 | 只看了 3 个用户，拒答 |

根因：RAG 检索 Top-5 只返回 5 条，LLM 拿不到"全部 8110 用户"去做聚合。

这不是 LLM 的问题，是架构缺一层。这类 query 需要：

```text
"美妆用户客单价分布"
  → LLM 生成 SQL: SELECT avg_amount FROM user_profile_vectors WHERE top_category='美妆'
  → 执行 SQL 得到 800+ 条
  → LLM 基于聚合结果回答
```

解决方向：加 SQL 生成 + 执行工具（Text2SQL），专门处理聚合/统计/分布类查询。
