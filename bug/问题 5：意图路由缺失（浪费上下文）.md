案例 CS-01、CS-02、CS-05（纯 SOP 查询）都召回了 user_profile。用户只是问流程，不需要画像数据。

根因：没有意图路由，所有查询都走"画像+文档"双路。

解决方向：编排层 Router——先判断 query 类型，再决定召回源：

python
if is_pure_procedure(query):       # "怎么操作"类
    retrieval_plan = {"wiki": 5, "profile": 0}
elif is_user_specific(query):      # "U2765 是什么"类
    retrieval_plan = {"wiki": 0, "profile": 5}
else:                              # 组合类
    retrieval_plan = {"wiki": 2, "profile": 3}
