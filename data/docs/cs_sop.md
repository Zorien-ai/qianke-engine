# 客服标准作业流程（SOP）

## 场景一：物流延迟投诉
1. 查询订单状态，确认是否已发货。
2. 若已发货且超过 7 天未更新，主动致歉。
3. 提供补偿方案：10 元无门槛券，或积分补偿。
4. 若用户坚持退款，引导至自助退款入口。
5. 记录工单，标记“物流延迟”。

## 场景二：商品质量问题
1. 请用户提供照片或视频证据。
2. 确认在退换货期内（签收后 7 天）。
3. 提供换货或退款选项，优先换货。
4. 若用户不满，升级至客服主管。
5. 记录工单，标记“质量问题”。

## 场景三：会员权益咨询
1. 查询用户会员等级和权益有效期。
2. 解释当前等级对应的权益。
3. 若用户接近升级，提示还差多少消费额。
4. 推荐续费或升级礼包。
5. 记录工单，标记“会员咨询”。

## 场景四：优惠券使用问题
1. 查询用户账户内可用券。
2. 解释使用门槛和有效期。
3. 若券已过期，视情况补发一张同等面额券。
4. 引导用户下次使用。
5. 记录工单，标记“优惠券”。
