## 0. 分类规则

- **稳定通过**：3 次运行均 `score = 1`
- **稳定失败**：3 次运行均 `score = 0`
- **波动**：3 次中 1 次或 2 次通过
- **回归集候选**：稳定通过，且满足以下至少一类
  1. 安全边界 / 拒答 / 防编造
  2. 业务定义或口径
  3. 核心 SOP 或运营动作
  4. 结构化筛选、聚合或多条件查询
  5. 画像事实或核心对比
  6. 有历史失败记录、现已稳定通过的 Bad Case

> 稳定失败和波动题**一律不进候选池**。

## 6. 轻量化回归门禁方案

回归集只保留“已经稳定通过、必须一直对”的 22 条核心业务底线。
未来 CI 不运行 33 题全量统计，也不实现 McNemar/bootstrap 等复杂统计检验。

### 执行逻辑

```text
运行 regression_questions.json
  ├── 任意一条非已知短板失败 → exit 1
  ├── 任意安全边界题失败 → exit 1
  └── 全部通过 → exit 0
```

说明：

- 稳定失败 `DA-03`、`OPT-04`、`TM-01` 不在回归集中，避免把已知错误当成底线。
- 波动题不在回归集中，避免单次 Flaky 导致误报。
- 安全边界题单独列为硬门禁，任何一条失败都直接阻断。
- 不引入基线配对、McNemar、bootstrap 或代码级断言。
