# C 端导航统一

日期：2026-11-14

## 问题

```text
CApp 独立端底部：聊 / 逛 / 订单 / 消息（4 个）
CShell 页面：首页 / 聊 / 逛 / 订单 / 消息（5 个）
同一 C 端两套导航，切换页面时底部 Tab 不一致
```

## 修复

```text
CApp 桌面侧栏统一为：首页 / 聊 / 逛 / 订单 / 消息
CApp 手机底部统一为：首页 / 聊 / 逛 / 订单 / 消息
首页目标：/c/home
聊目标：/c/app
逛目标：/c
订单目标：/c/orders
消息目标：/c/social
```

## 验证

```text
390 视口：5 个 Tab，无横向溢出
CApp：首页 / 聊 / 逛 / 订单 / 消息
CShell：首页 / 聊 / 逛 / 订单 / 消息
桌面侧栏同样 5 项
```
