## 判定

每个用例检查：

```text
route
卡牌 user_id
回答关键词
来源文档 / 来源池
```

不是只比字符串；例如 `buyer_217` 必须返回精确卡牌和冷启动属性，买绿茶必须能列出具体用户并说明检索范围。

## 边界

- Golden 运行依赖 `m_sim_tea` 的导入池已构建；未构建会先失败并提示。
- 回答是 LLM 生成，因此关键词断言刻意按“语义要点”写，不绑定固定句式。
- 本集用于回归，不代表生产准确率；生产需扩充真实问题集和人工标注。
