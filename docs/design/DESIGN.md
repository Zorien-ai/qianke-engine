## 0. 为什么需要这份规范

当前问题不是“颜色不好看”，而是：

```text
B 端像 SaaS 控制台
C 端像聊天工具
A 端像临时表格页
官网像另一个产品
```

每个页面单独看都成立，放在一起缺少家族感。

但统一不等于所有页面长得一样。真正的统一应该是：

```text
同一套中性色、字体、间距、圆角、边框、组件解剖
+
不同的布局、密度、内容组织、情绪温度
```

本规范定义**不可随意变化的底层**，以及**允许每个端不同的表达层**。

## 1. 设计原则

### 1.1 中性为底，颜色为信号

- 大面积中性灰 / 纸色。
- 颜色只用于：主操作、状态、数据重点、风险。
- 禁止大面积彩色背景、彩色卡片墙、彩色渐变。

### 1.2 结构制造差异，不靠装饰制造差异

不同端的区别来自：

```text
布局
信息密度
导航形态
内容组织
语气
```

不是来自：

```text
更多颜色
更多圆角
更多阴影
更多动效
```

### 1.3 哑光、纸面、证据感

- 所有表面默认哑光。
- 边框优先于阴影。
- 阴影只用于浮层，不用于普通卡片。
- 禁止霓虹、发光、玻璃拟态、彩色渐变。

### 1.4 8px 网格

- 主间距使用 8 的倍数。
- 4px 只作为半格，用于图标与文字微调。
- 不出现 13px、17px、23px 这类随手值。

### 1.5 去 AI 味

禁止：

```text
紫蓝渐变
大面积玻璃卡片
每页一个巨大 Hero
无意义 emoji
“赋能 / 智能体魔法 / 一站式” 空话
所有按钮都圆成胶囊
所有卡片都加阴影
```

## 2. 统一层：Design Tokens

### 2.1 中性色阶

以 C 端石墨色为基准，向纸白方向延伸。冷暖轻微，不偏蓝紫。

```css
:root {
  /* 深色 / 石墨 */
  --ds-ink-950: #0F0F11;
  --ds-ink-900: #131315;
  --ds-ink-850: #161618;
  --ds-ink-800: #1B1B1E;
  --ds-ink-750: #202023;
  --ds-ink-700: #232326;
  --ds-ink-650: #29292D;
  --ds-ink-500: #55555C;
  --ds-ink-400: #707078;
  --ds-ink-350: #85858C;
  --ds-ink-300: #A3A3AA;
  --ds-ink-200: #C8C8CD;
  --ds-ink-100: #E7E7E9;

  /* 纸面 / 浅色 */
  --ds-paper-0: #FFFFFF;
  --ds-paper-50: #F7F7F5;
  --ds-paper-100: #EFEFEB;
  --ds-paper-200: #E4E4DE;
  --ds-paper-300: #D2D2CB;
  --ds-paper-400: #B0B0A8;
  --ds-paper-500: #8A8A82;
  --ds-paper-550: #6B6B64;
  --ds-paper-600: #5C5C56;
  --ds-paper-700: #3A3A36;
  --ds-paper-800: #242421;
  --ds-paper-900: #171715;
}
```

### 2.2 唯一品牌强调色

产品级强调色只保留一个：**灰青**。

```css
--ds-accent: #6F8A8C;
--ds-accent-strong: #587376;
--ds-accent-soft: rgba(111, 138, 140, 0.14);
--ds-accent-line: rgba(111, 138, 140, 0.32);
```

它用于：

```text
焦点环
当前选中项
关键链接
主按钮的部分场景
数据图的重点系列
```

不用于：

```text
大面积背景
每张卡片顶部色条
每个标签
```

### 2.3 语义色

低饱和，避免交通灯感。

```css
--ds-positive: #6F8F7A;
--ds-positive-soft: rgba(111, 143, 122, 0.13);
--ds-positive-text: #4F6E5B;
--ds-warning: #A08A64;
--ds-warning-soft: rgba(160, 138, 100, 0.14);
--ds-warning-text: #7A6340;
--ds-negative: #A17171;
--ds-negative-soft: rgba(161, 113, 113, 0.13);
--ds-negative-text: #8A4F4F;
--ds-info: #6F8494;
--ds-info-soft: rgba(111, 132, 148, 0.13);
--ds-info-text: #4E6275;
```

原则：

- 状态不能只靠颜色表达，必须同时有文字。
- 成功 / 警告 / 风险只在语义位置出现，不做装饰。
- 浅色背景上的小字号状态文字使用 `*-text`，不要直接使用低对比的 `positive` / `warning` / `negative`。

### 2.4 文字颜色角色

```css
/* 浅色纸面 */
--ds-text-primary: var(--ds-paper-900);
--ds-text-secondary: var(--ds-paper-600);
--ds-text-muted: var(--ds-paper-550);

/* 深色石墨 */
--ds-text-primary-dark: var(--ds-ink-100);
--ds-text-secondary-dark: var(--ds-ink-300);
--ds-text-muted-dark: var(--ds-ink-350);
```

不要混用：

- 浅色页面的 muted 用 `--ds-paper-550`，不要用 `--ds-paper-500`。
- 深色页面的 muted 用 `--ds-ink-350`，不要用 `--ds-ink-400`。
- `--ds-paper-500` / `--ds-ink-400` 只用于非文本装饰、图标底、分隔辅助。

#### 对比度底线

| 组合 | 对比度 | 用途 |
|---|---:|---|
| `ink-100` / `ink-950` | 约 13.5:1 | 深色主文字 |
| `paper-900` / `paper-50` | 约 15.5:1 | 浅色主文字 |
| `paper-600` / `paper-50` | 约 6.3:1 | 浅色次要文字 |
| `paper-550` / `paper-50` | 约 5.0:1 | 浅色 muted |
| `ink-300` / `ink-950` | 约 7.6:1 | 深色次要文字 |
| `ink-350` / `ink-950` | 约 5.2:1 | 深色 muted |
| `accent-strong` / `white` | 约 5.1:1 | 浅色主按钮白字 |
| `accent` / `ink-950` | 约 5.2:1 | 深色焦点 / 链接 |
| `positive-text` / `white` | 约 5.7:1 | 浅色成功文字 |
| `warning-text` / `white` | 约 5.7:1 | 浅色警告文字 |
| `negative-text` / `white` | 约 6.3:1 | 浅色风险文字 |

- 普通正文必须 ≥ 4.5:1；大字 / 非文本 UI ≥ 3:1。
- 浅色页面上不要用 `--ds-accent` 直接写小字，使用 `--ds-accent-strong`。
- 实心主按钮在浅色背景使用 `--ds-accent-strong` + 白字；深色背景可用 `--ds-accent` + `--ds-ink-950` 字。

### 2.5 字体

```css
--ds-font-sans:
  "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI",
  "PingFang SC", "Microsoft YaHei", sans-serif;
--ds-font-mono:
  "SFMono-Regular", Consolas, "Liberation Mono", Menlo, monospace;
```

使用范围：

```text
正文：sans
ID / 金额 / 时间 / 指标 / 表格数字：mono
代码 / SQL / 引用键：mono
```

### 2.6 字号与字重

| Token | 字号 | 行高 | 用途 |
|---|---:|---:|---|
| `2xs` | 10px | 14px | kicker、表头辅助、气泡时间 |
| `xs` | 11px | 16px | 标签、辅助说明 |
| `sm` | 12px | 18px | 次要正文、卡片说明 |
| `base` | 13px | 20px | B 端正文、表格主体 |
| `md` | 14px | 22px | 移动端正文、主要阅读 |
| `lg` | 16px | 24px | 区块标题、卡片标题 |
| `xl` | 20px | 28px | 页面主标题 |
| `2xl` | 24px | 32px | C 端页面标题、看板标题 |
| `display` | 32px | 40px | 官网 Hero，仅此一处 |

字重：

```text
400 正文
500 强调 / 按钮 / 标签
600 标题 / 关键数字
```

禁止：

```text
700 以上
中文加 letter-spacing（kicker 除外）
正文使用全大写英文
```

### 2.7 间距

```css
--ds-space-2xs: 4px;
--ds-space-xs: 8px;
--ds-space-sm: 12px;
--ds-space-md: 16px;
--ds-space-lg: 24px;
--ds-space-xl: 32px;
--ds-space-2xl: 48px;
--ds-space-3xl: 64px;
```

使用：

```text
页面左右边距：24 / 32
卡片内边距：16 / 20
卡片间距：12 / 16
区块间距：24 / 32
移动端：12 / 16
```

### 2.8 圆角

```css
--ds-radius-control: 8px;
--ds-radius-card: 12px;
--ds-radius-panel: 16px;
--ds-radius-full: 999px;
```

规则：

- 按钮、输入框：8
- 卡片、消息气泡：12
- 大面板、抽屉：16
- 仅状态标签 / 头像使用全圆
- **禁止所有东西都 18–24px 圆角**

### 2.9 边框与阴影

```css
--ds-border: 1px solid var(--ds-paper-200);
--ds-border-dark: 1px solid var(--ds-ink-650);
--ds-shadow-raised: 0 2px 8px rgba(15, 15, 17, 0.06);
--ds-shadow-overlay: 0 12px 32px rgba(15, 15, 17, 0.16);
```

规则：

- 普通卡片：边框，不加阴影。
- 浮层 / 下拉 / 弹窗：`--ds-shadow-overlay`。
- 禁止“边框 + 大阴影 + 彩色光晕”同时出现。

### 2.10 动效

```css
--ds-duration-fast: 120ms;
--ds-duration-base: 180ms;
--ds-duration-slow: 240ms;
--ds-ease: cubic-bezier(0.2, 0, 0, 1);
```

规则：

- 只用于 hover、展开、切换、骨架屏。
- 不做弹跳、不做大幅位移、不做自动循环动画。
- 必须支持 `prefers-reduced-motion`。

### 2.11 数据可视化

```css
--ds-chart-1: #6F8A8C;
--ds-chart-2: #8A8A82;
--ds-chart-3: #A08A64;
--ds-chart-4: #6F8494;
--ds-chart-5: #A17171;
```

- 单系列优先中性灰 + 一个强调色。
- 多系列按上面顺序使用，不超过 5 色。
- 禁止彩虹色、渐变填充、3D 柱状图。
- 图表必须有标题、单位、图例或直接标注。

## 3. 多种气候

统一的是 Token 和组件解剖，不统一的是**信息结构**。

| 端 | 画布 | 密度 | 导航 | 强调色用途 | 典型内容 |
|---|---|---|---|---|---|
| B 工作台 | 纸白 / 深色纸 | 中高 | 左侧栏 | 只标当前操作 | 分析、表格、Agent 轨迹 |
| C App | 纸白 | 低中 | 会话列表 / 移动端全屏 | 极少，主要用中性 | 对话、报价、订单确认 |
| 石墨 C App（备用） | 石墨 | 低中 | 会话列表 / 移动端全屏 | 极少 | 夜间主题 |
| A 审计 | 纸白 / 石墨 | 高 | 左侧栏 | 只标风险与状态 | 表格、筛选、证据链 |
| 官网 | 纸白 | 低 | 顶部导航 | 品牌强调 | 叙事、案例、入口 |

### 3.1 B 工作台：精确的纸面

关键词：

```text
纸面
数据分析
高信息密度
可扫描
证据感
```

规则：

- 默认浅色纸面，可跟随系统深色。
- 侧栏固定，主内容最大宽度约 1180–1200。
- 页面标题 20–24，不使用巨大 Hero。
- 表格、表单、Agent 轨迹是主角。
- 强调色只出现在：当前导航、主按钮、焦点、选中行。
- 不使用聊天气泡作为主布局。

### 3.2 C App：纸面极简对话

关键词：

```text
纸白
对话优先
低密度
无重气泡
细线分割
可触碰
```

规则：

- 初始页是伙伴对话，不是商城首页。
- 桌面三栏：会话 / 对话 / 上下文或报价。
- 移动端一次只做一件事：会话列表或对话。
- 对方消息用「名称 + 文本」行式结构；自己消息用浅灰纸面块。
- 不用深色实底气泡，不用大面积彩色。
- 输入区是细边框容器，确认按钮用黑色。
- 强调色只用于在线状态、待确认、关键数字。
- 不用企业工作台的侧栏、页头、KPI 卡。
- C 端可以更暖，但不使用 emoji、感叹号堆叠、卖萌话术。

### 3.2.1 石墨 C App（备用）

如果后续需要夜间陪伴感，可保留一套石墨主题：

```text
背景 #0F0F11
面板 #161618
文字 #E7E7E9
```

它只作为主题切换，不改变白色默认版的布局与组件契约。

### 3.3 A 审计：冷峻的证据台

关键词：

```text
账本
证据
筛选
可核对
```

规则：

- 表格优先，卡片其次。
- 页面顶部是筛选栏，不是营销 Hero。
- 指标卡只保留 3–4 个，数字用 mono。
- 订单 / 报价 / 状态 / 金额必须能逐行核对。
- 颜色只用于：已确认、待确认、异常、风险。
- 不使用 C 端聊天气泡，不使用 B 端的 Agent 轨迹。

### 3.4 官网：留白与叙事

关键词：

```text
品牌
留白
大字号
少控件
```

规则：

- 使用 `display` 字号，但只用于 Hero。
- 一屏一个主张，不做功能卡片墙。
- 强调色只用于主 CTA 与关键线。
- 不使用工作台组件堆首页。

### 3.5 白对话：当前实现

当前 C 端 App 已按白色极简对话落地：

```text
画布：纯白
侧栏 / 上下文：FCFCFB
对方消息：行式文本
自己消息：浅灰纸面块
输入：细边框
报价：白底细边框
确认按钮：黑色
```

实现文件：

```text
web/src/views/CApp.vue
web/public/manifest.webmanifest
web/index.html
```

预览：

```text
/v2/#/c/app
/v2/design-preview.html?focus=white
```

## 4. 组件契约

### 4.1 按钮

| 类型 | 高度 | 圆角 | 背景 | 文字 |
|---|---:|---:|---|---|
| Primary | 32 / 36 | 8 | `--ds-accent-strong` 或深色 ink | 白 / 反色 |
| Secondary | 32 / 36 | 8 | 透明 | `--ds-text` |
| Ghost | 28 / 32 | 8 | 透明 | `--ds-text-2` |
| Danger | 32 | 8 | `--ds-negative-soft` | `--ds-negative-text` |

规则：

- 一个视图只能有一个 Primary。
- 不使用渐变、发光、彩色阴影。
- 焦点环：`outline: 2px solid var(--ds-accent); outline-offset: 2px`。
- 移动端最小点击区域 44×44。

### 4.2 输入框

- 高度 32 / 36；圆角 8；1px 边框。
- Label 使用 `xs`，不与 placeholder 混用。
- Focus：边框变 accent + 2px 焦点环。
- 错误：边框 negative + 下方 `xs` 文案，不只变红。
- 搜索框不用巨大圆角胶囊，除非是 C 端移动输入。

### 4.3 卡片

- 圆角 12；1px 边框；默认无阴影。
- 内边距 16 / 20。
- 同一屏卡片不要全部等宽等高；按信息优先级组织。
- 卡片内最多一个主操作。
- 不使用顶部彩色条作为装饰。

### 4.4 表格

- 行高 40–44；表头 `xs` muted。
- 数字右对齐，mono；金额保留两位。
- 表头 sticky；不使用斑马纹，使用 1px 分隔线 + hover。
- 空态必须说明“为什么为空 / 下一步”。
- 分页控件固定底部，显示页码与总数。

### 4.5 标签

- 高度 20–22；圆角 999；字号 9–10。
- 背景使用语义 soft；文字使用对应语义色。
- 一个标签只表达一个状态。
- 禁止用标签堆满卡片。

### 4.6 对话消息（仅 C 端）

- 对方：左侧「名称 + 时间 + 文本」行式结构，默认无重气泡。
- 自己：右侧浅灰纸面块，1px 细边框；不使用深色实底。
- 圆角 12；最大宽度 78%；正文 `md` / 14。
- 时间戳 10px，放在文本末尾或组尾，不使用时间分隔大标题。
- 不使用彩色渐变气泡。
- 店宠与伙伴通过头像、名称、轻微底色区分，不通过夸张颜色。

### 4.7 任务卡（B 端任务看板）

- 圆角 12；边框；内边距 14–16。
- 标题 13/600；说明 12；元信息 10。
- 状态在标题同行，使用标签。
- 操作靠右；一个主操作 + 一个次操作。
- 不使用左侧彩色竖条。

### 4.8 空态 / 加载 / 错误

```text
空态：一句事实 + 一句下一步 + 一个操作
加载：骨架屏，不用全屏 spinner
错误：说明发生了什么 + 可重试
```

禁止：

```text
“暂无数据” 四个字占满页
大片插画
自动轮播提示
```

## 6. 内容与语气

### B 端

- 直接、可验证、少形容词。
- 说“依据 / 口径 / 查询结果”，不说“智能洞察”。
- 错误信息写清楚下一步。

### C 端

- 短句、具体、有温度但不卖萌。
- 不用“亲 / 宝子 / 魔法 / 一键起飞”。
- 不用连续感叹号与 emoji。
- 伙伴只做建议，成交必须用户确认。

### A 端

- 审计语言：待确认、已确认、已完成、异常、差额。
- 不写营销话术。
- 每个数字能追溯到订单 / 报价 / 时间。

## 7. 不要太像：反同质化规则

### 必须不同

| 维度 | B | C | A |
|---|---|---|---|
| 画布 | 纸面 | 石墨 | 纸面 / 石墨 |
| 首屏 | 工作台概览 | 伙伴对话 | 审计筛选 |
| 导航 | 固定侧栏 | 会话列表 | 固定侧栏 |
| 密度 | 中高 | 低中 | 高 |
| 主角组件 | 表格 / Agent 轨迹 | 聊天气泡 | 审计表 |
| 颜色角色 | 操作 | 状态 / 关系 | 风险 / 证据 |

### 必须相同

```text
中性色阶
字体与字号层级
8px 间距
8 / 12 / 16 圆角
边框优先
低饱和语义色
焦点环
空态结构
```

### 判定标准

如果把 B、C、A 三张截图并排：

- 能看出是同一个产品 → 通过。
- 能一眼分出工作台、聊天、审计 → 通过。
- 三张图像同一个模板换标题 → 不通过。

## 8. 现有实现映射

### 当前文件

```text
web/src/styles/main.css        B 端全局变量与组件
web/src/views/CApp.vue         C 端独立 --c-* 变量与布局
web/src/views/CAdminAudit.vue  A 端审计页
web/src/views/AgentActions.vue B 端任务看板
web/src/App.vue                B 端外壳
```

### 迁移顺序

```text
1. 在 main.css 增加 --ds-* Token，不改变现有视觉效果
2. CApp 的 --c-* 中性色映射到 --ds-ink-*
3. B 端把 --primary / --accent 收敛到 --ds-accent
4. 组件逐个替换硬编码颜色 / 圆角 / 阴影
5. 统一按钮、表格、标签、空态
6. 桌面 / 移动截图对比
```

### 迁移约束

- 不改变业务行为和接口。
- 不做一次性全站重绘。
- 每步可回滚。
- 先统一 Token，再统一组件，最后调整布局。
